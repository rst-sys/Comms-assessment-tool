# Protocols waiting to be integrated

Drop protocol files here.

These are the replies Claude produced from `PROTOCOL-PROMPT.md`, saved as
Markdown and uploaded straight from the GitHub website. They are raw drafts,
not part of the tool yet.

Nothing in this folder runs. The review engine never reads it. A protocol only
takes effect once it has been turned into code in `src/engine/protocols.ts`,
with tests, which happens here in the chat.

Name each file after the kind of communication it covers — `crisis-statement.md`,
`apology.md`, `investor-communication.md` — so it is obvious what is waiting.

Once a protocol has been integrated, its file stays here as the record of what
it was built from.
